# mabuonomo.github.io

Personal website and technical blog of Mario Buonomo, built with [Astro](https://astro.build/) and deployed statically to GitHub Pages.

## Local Development

### With Docker Compose

```bash
docker compose up
```

Then open [http://localhost:4321](http://localhost:4321).

### With Node.js

```bash
npm install
npm run dev
```

## Static Build

```bash
npm run build
```

Output is generated in `dist/`.
